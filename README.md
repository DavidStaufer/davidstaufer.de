# DavidStaufer.de

Mein Leben als Sonnensystem: Ich bin die Sonne. Studium, Projekte, Arbeit und Hobbys kreisen als Planeten um mich, Semester und Module als Monde. Aus der Nähe verwandelt sich jeder Mond in ein kleines 3D-Modell. Wer lieber liest, findet alles auch in der [klassischen Ansicht](https://davidstaufer.de/klassisch/).

## Technik

- [Astro](https://astro.build) für die statische Seite, eine Markdown-Datei pro Knoten
- [three.js](https://threejs.org) für das Sonnensystem und die 3D-Modelle
- TypeScript, keine externen Fonts, kein Tracking

```bash
npm install
npm run dev     # http://localhost:4321
npm run build   # nach dist/
```
